# Syntax Skill Repository

This repository is designed to work with both Codex and Cursor.

- For Codex, use `SKILL.md` as the entrypoint and route into `references/` as needed.
- For Cursor, use `.cursor/rules/syntax-skill.mdc` as the project rule.
- In either tool, start with `references/agent-design-protocol.md`, then load only the domain references relevant to the current architecture task.
- Preserve the distinction between model-generated candidates and accepted facts, plans, actions, and verification results.
- Keep source citations traceable to chapter, section, printed page, XHTML file, and anchor.
