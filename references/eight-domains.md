# Eight Domains At A Glance

| # | Domain | Main engineering question |
|---|---|---|
| 1 | Form vs. meaning | What state must exist outside the language model? |
| 2 | Dependency graphs and task representation | How should a goal become an executable graph? |
| 3 | Noisy channel | When should the system infer, ask, or refuse? |
| 4 | Lossy memory | What may be compressed, and how can it be recovered? |
| 5 | Locality and state distance | Which facts must be close to the action that uses them? |
| 6 | Planning vs. generation | Which component proposes, and which component commits? |
| 7 | Agent evaluation | How do we grade partial success and repairability? |
| 8 | Candidate generation vs. arbitration | Which claims require tools, policies, or human confirmation? |

The eight domains are applications of the book's distinctions, not claims that the book directly discusses modern agent architecture.
